1 Was ist Kolonne Live?

Hilfe für Motorradgruppen – besonders Harley-Fahrer – den Überblick in der Kolonne zu behalten.

Freiheit auf zwei Rädern – die Kolonne im Blick behalten

Wofür die App da ist

Der Anführer fährt vorne. Dahinter mehrere Bikes. In Kurven, an Ampeln oder beim Abbiegen verliert man leicht jemanden. Kolonne Live zeigt in Echtzeit, ob alle noch dran sind, ob eine Lücke entsteht oder jemand vom Kurs abweicht – direkt im Smartphone-Browser, ohne App-Store-Installation.

Grün = dran Gelb = Lücke Rot = steht / offline Violett = falsche Richtung

2 Wann kommt welche Warnung?

Zeiten und Entfernungen – die Schwellwerte aus der App (anpassbar in der index.html).

Chrom, Asphalt, Abstand – die App rechnet mit Metern und Sekunden
WertStandardBedeutung
GAP_M 400 m Ab diesem Abstand: Status Lücke (gelb)
LOST_M 1000 m Sehr großer Abstand → eher abgehängt (rot)
LATERAL_M 350 m Seitliche Abweichung vom Kurs → violett (falsch abgebogen?)
OFFLINE_MS 90 s Kein Positions-Signal → offline. Meldung: „sendet seit über 90 s nicht mehr“
SEND_TIMEOUT 20 s Mindest-Intervall für Positions-Updates (auch ohne große Bewegung)
LEADER_TIMEOUT_MS 2 min Kein Signal vom Anführer → Warnung bei den Fahrern
SEND_MOVE_M 30 m Zusätzlich senden, wenn man sich so weit bewegt hat
In Anwendersprache
  • Grün – Abstand und Signal in Ordnung, du bist dran.
  • Gelb – Du hängst spürbar zurück (hunderte Meter).
  • Rot – Sehr großer Abstand oder länger kein GPS-Signal (über 90 Sekunden).
  • Violett – Du scheinst vom Kurs der Kolonne abzuweichen.

Die Werte sind auf Landstraße und typische Kolonnenfahrt ausgelegt. Für Stadt oder sehr große Gruppen können sie in der index.html angepasst werden.

3 So läuft eine Tour

Rollen, Beitritt und Praxis-Tipps.

Gemeinsam raus – Anführer vorne, Fahrer im Blick der App
  1. Anführer startet „Ich bin Anführer“ → optional Kolonnen-Name und Club wählen → starten. QR-Code oder Link teilen.
  2. Fahrer treten bei QR scannen oder Raum-Code eingeben, Namen und Verein/Club wählen → Beitreten.
  3. Unterwegs Anführer sieht Avatar-Reihe/Liste mit Farben. Fahrer sehen die eigene Ampel. Display idealerweise an lassen.
  4. Tourende Anführer beendet die Kolonne. Optional Track als GPX speichern oder auf der Karte ansehen.
Tipps für die Praxis
  • Bildschirm an lassen – die App fordert Wake-Lock an (iOS oft eingeschränkt).
  • Guter GPS-Empfang (nicht unter dickem Material in der Tasche).
  • Seite nur über HTTPS nutzen (GitHub Pages ist das automatisch).
  • Bei Offline: wieder Empfang, App offen, ggf. „Ich bin wieder da“.

4 Wartung – das Wichtigste

Damit die App dauerhaft läuft: Supabase, GitHub, Icons.

⚡
Supabase Free-Tier kann nach ca. 7 Tagen ohne Aktivität pausieren. Dann kurz einloggen und Projekt wiederherstellen – oder 1–2× pro Woche die App öffnen.
Supabase (Live-Verbindung)

Realtime-Channel pro Raum-Code. Ohne aktives Projekt keine Kolonne.

  • Free-Tier: Pause nach Inaktivität möglich
  • Wieder aktivieren: Supabase-Dashboard → Project → Restore
  • Optional: automatischer Ping (cron-job.org) auf die Projekt-URL
  • Anon-Key & URL stehen in der index.html
GitHub & GitHub Pages
  • Repo muss öffentlich bleiben für kostenloses Pages-Hosting
  • Live-Seite: ed-fun.github.io/Kolonne
  • index.html liegt im Root von Branch main
  • Push auf main → automatisches Deployment
  • Andere können den Code lesen, aber nicht ohne Rechte ändern
Club-Icons (Ordner icons/)

Struktur auf main:

index.html
icons/
  01_Harley-Pfalz-Club.svg
  02_Einzelteilnehmer.svg
  03_Harley_Friends_Saarlouis.svg
  04_nix.svg
  …
  • Schema: XX_Club-Name.svg (Nummer = Sortierung)
  • Dateien mit _nix im Namen → nicht im Dropdown
  • Neuer Club = nur SVG hochladen, App neu laden
  • Ordnername genau icons (klein) – kein Branch „Icons“!
Schwellwerte in der index.html

Suche im Script nach „Schwellwerte“:

  • OFFLINE_MS – ms bis offline (90000 = 90 s)
  • SEND_TIMEOUT – min. Sendeintervall
  • LEADER_TIMEOUT_MS – Timeout Anführer
  • GAP_M / LOST_M / LATERAL_M – Abstände in Metern

5 Technik (für Entwickler)

Architektur und Datenfluss in Kurzform.

Eine HTML-Datei, Realtime, GPS – bewusst schlank gehalten

Architektur

  • Reine Frontend-App: eine index.html, kein Build
  • Hosting: GitHub Pages
  • Echtzeit: Supabase Realtime (Broadcast pro Raum)
  • Standort: Geolocation API + optional Wake Lock
  • Clubs: GitHub Contents API auf icons/, Cache in localStorage
  • QR-Code: reine JS-Implementierung (kein CDN)
Datenfluss

Anführer und Fahrer joinen denselben Channel (Raum-Code). Jeder sendet Position und Metadaten (Name, Club). Der Anführer berechnet Status (ok / gap / stop / off / wrong) und verteilt den Überblick. Fahrer sehen vor allem die eigene Ampel.

6 Wartungs-Checkliste

Zum Abhaken – speichert sich nicht, ist aber gut als Ritual.

  • Supabase-Projekt aktiv (nicht pausiert)?
  • Repo öffentlich, Branch main aktuell?
  • index.html im Root von main?
  • Ordner icons/ auf main mit nummerierten SVGs?
  • Nach Icon-Upload App hard-reload getestet?
  • Impressum / Kontakt in der Hilfe noch korrekt?
  • Bei Bedarf OFFLINE_MS / Abstände angepasst?
